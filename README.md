# TOTA-Waste-Water-Dashboard

An interactive **R Shiny dashboard hosted by Posit Connect Cloud** that brings together publicly available wastewater data for the Thompson Okanagan region.

The dashboard was developed by the **Thompson Okanagan Tourism Association (TOTA)** to support wastewater management reporting for the **UN Tourism International Network of Sustainable Tourism Observatories (INSTO)**. This dashboard contributes to ongoing efforts to better understand the relationship between wastewater and tourism in the Thompson Okanagan Region.

## Dashboard

**Live App:** https://tota-waste-water-dashboard.share.connect.posit.cloud/
## Features

* Effluent - systems and volume of effluent deposited across the region.
* Volume Processed - total volume processed across drainage regions.
* Population Served - total population served by wastewater systems.
* Volume Per Person - amount of wastewater processed per person.
* KPIS, interactive charts, maps, and historical comparisons.
